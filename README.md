
# SkillQuest

SkillQuest is a gamified hiring platform that helps recruiters evaluate candidates through interactive cognitive and functional-skill assessments.

## Features

- Multi-role authentication for applicants, employees, clients, and administrators
- Interactive assessments including Minesweeper, Unblock Me, and Water Capacity
- Timed challenges with scoring, progress tracking, and leaderboards
- Applicant profiles, chatbot support, and an admin dashboard
- Assessment integrity controls, including fullscreen and tab-switch detection

## Tech Stack

React, TypeScript, Vite, Tailwind CSS, React Context, and Local Storage.

## Getting Started

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```
